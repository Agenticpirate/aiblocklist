# AIBlockList — Founder Decision Register (Task D)

- **Version:** 1.0 (Pre-Implementation Gate)
- **Rule:** Per Section 27 (Task F), production code implementation will not begin until you review and approve the blocking pre-implementation decisions below.
- **Legend:** `[BLOCKING PHASE 1]` = must decide before scaffolding production code; `[BLOCKING PHASE 2]` = must decide before opening reporting/moderation/appeals; `[BLOCKING PHASE 3–4]` = must decide before public API/federation/extension launch.
