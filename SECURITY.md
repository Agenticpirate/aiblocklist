## 🛡️ Reporting a Vulnerability

The AIBlockList team takes the security and integrity of our intelligence infrastructure seriously. If you discover a security vulnerability or potential data exposure, please disclose it responsibly.

### How to Report

- **Email**: Send detailed information regarding the vulnerability to `security@aiblocklist.com` or contact [@Agenticpirate](https://x.com/Agenticpirate) on 𝕏.
- **Do NOT** open a public GitHub issue for sensitive security vulnerabilities.

### What to Include

1. Type of issue (e.g., SQL injection, authentication bypass, SSRF, XSS).
2. Step-by-step instructions or proof-of-concept payload to reproduce the issue.
3. Affected endpoint, file, or component.
4. Proposed remediation or mitigation steps if available.

### Our Commitment

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will coordinate with you regarding the fix timeline and provide public credit in release notes upon patch deployment.
